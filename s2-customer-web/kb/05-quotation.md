# 報價流程

## 參考價格（未稅，虛構示範用）

| 品項 | 參考價 |
| --- | --- |
| DR-300 單機 | 新台幣 68 萬元起 |
| DR-800 單機 | 新台幣 115 萬元起 |
| 自動充電樁 | 新台幣 6 萬元／座 |
| 示範調度平台授權 | 新台幣 30 萬元起（依台數） |
| 年度維護合約 | 單機售價的 8%／年 |

實際價格依台數、頂部模組、場地施工與系統整合範圍而定，**以正式報價單為準**。

## 報價步驟

1. 客戶填寫需求表：搬運物品、重量、每日趟數、場地平面圖。
2. 業務在 3 個工作天內安排現場勘查或視訊評估。
3. 提供方案建議書與正式報價單（有效期 30 天）。
4. 可安排 2 週的到場試用（POC），試用費用可折抵正式訂單。
5. 簽約後交期約 8～12 週。

## 付款條件

一般為訂金 30%、到貨 60%、驗收完成 10%。大量採購或租賃方案請洽業務。
