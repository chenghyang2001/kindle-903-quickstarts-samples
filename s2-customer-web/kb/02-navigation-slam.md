# 導航與 SLAM

## 導航方式

DR 系列採用**雷射 SLAM 自然導航**，不需要在地面貼磁條、二維碼或反光板。

- 建圖：第一次部署時，由工程師用遙控方式推著機器人繞場地一圈，約 1 小時可完成 5,000 平方公尺的地圖。
- 定位：以 2D 光達點雲比對地圖，搭配輪式里程計與 IMU 融合，定位精度 ±10 mm。
- 路徑規劃：全域路徑用 A* 搜尋，區域避障用動態視窗法；遇到障礙物會繞行，無法繞行時停車等待並通知。
- 多車調度：由「示範調度平台」統一派工與交通管制，單一場域建議最多 50 台。

## 環境限制

- 地面需平整，坡度不超過規格表的爬坡能力。
- 大面積玻璃牆或全空曠場地（例如沒有任何牆柱的大倉庫中央）會降低定位穩定度，可加裝少量反光板輔助。
- 地圖更新：貨架位置大幅變動後，建議重新建局部地圖，約 15 分鐘。

## 系統整合

提供 REST API 與 MQTT 介面，可和 WMS／MES 對接任務。
